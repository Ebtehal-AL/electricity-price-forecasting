# Electricity Price Forecasting

Bachelor's thesis exploring quarter-hourly electricity price forecasting using Python and statistical and machine learning models.

## Overview
This project investigates electricity price forecasting through data cleaning, feature engineering, model development, and evaluation.

## Models
- LEAR
- XGBoost
- LSTM

## Repository Structure
- `notebooks/`: Data preparation, feature engineering, modeling, and analysis
- `data/`: Datasets, prepared features, and saved model outputs
- `results/`: Forecast visualizations and comparison plots

## Technologies
Python · Pandas · Jupyter Notebook · XGBoost · LSTM
